## 5. NET TAVSİYE

### Sonuç: **KAPALI KALMALI** (Nötr → Karmaşıklık değmez + HARVEY kirlenme riski)

**Gerekçe:**

1. **Hiçbir filmde gerçek yönetmen kurtarılmadı.** Garble filmlerinde (FRANKIE, HARVEY, SILVERADO) master PNG yönetmeni bulmadı. Temiz filmlerde (HIRSIZ) zaten vardı.

2. **Master eklenen satırların %96'sı başrol cast veya yönetmen değil.** Dağılım: garble tekrar (%36) + rol etiketi (%30) + teknik ekip (%23) + kurumsal (%8). Rol-eval LLM'inin bu gürültüyü filtrelemesi bekleniyor — ama filtre ne kadar güvenilir bilinmiyor.

3. **HARVEY'de küçük kirlenme tespit edildi.** Master "WİLLİAM DANİELS" (görüntü yönetmeni) ekledi; basit rol-eval bunu yönetmen olarak atadı. Production `credit_text_read.py`'deki DIRECTED BY etiket + KB filtresi ile büyük olasılıkla filtrelenecek — ama risk var.

4. **Satır şişmesi önemli:** SILVERADO OFF=235 → ON=374 (+59%), HIRSIZ OFF=180 → ON=306 (+70%). Bu şişme LLM'in rol-eval bağlamını kötüleştirebilir (num_ctx sınırı).

5. **Koşul (a) sağlanmadı:** "temiz kontroller bozulmadı VE ≥1 filmde düzeltti" — düzelten film yoktu.

### Öneri: Master-PNG koşulunun değerli olabilmesi için şu önkoşullar gerekli:

- `compose_hybrid` kalitesini ölçmek: master.png gerçekten daha iyi bir görüntü mi üretiyor?
- Master-only satırlara ek garble filtresi: `_glm_garble()` + `_glm_only_keep()` zinciri zaten var ama yeterli değil; bozuk tekrarları (`STÉPHEM TÓHDŁOWSKY` = `STEPHEN TOBOLOWSKY` tekrar) yakalamıyor.
- Fold-deduplikasyonu güçlendirmek: OFF'ta zaten görülen isimlerin garble varyantları eklenmemeli (edit-distance ≥ 0.85 eşiği).

**Şimdilik:** `MITAS_MASTER_PNG` default **KAPALI** kalsın. Commit a54f166023 doğru mimariye sahip ancak ölçüm sonucu "karmaşıklık değmez" diyor.

## Komut Özeti

```
# OCR OFF (her film için)
$env:MITAS_MASTER_PNG="0"; $env:MITAS_OCR_GLM_CONSENSUS="0"
python venvs\ocr\Scripts\python.exe scripts\_pipe_ocr.py --frames frames\giris frames\cikis --out outputs\_ab\<FILM>\off

# OCR ON (her film için)
$env:MITAS_MASTER_PNG="1"; $env:MITAS_OCR_GLM_CONSENSUS="0"
python venvs\ocr\Scripts\python.exe scripts\_pipe_ocr.py --frames frames\giris frames\cikis --out outputs\_ab\<FILM>\on

# Rol-eval (her kunye.txt için)
set MITAS_CREDIT_TEXT_MODEL=qwen3:8b-atlas1
python Python310\python.exe scripts\_pipe_credit_text.py --ocr outputs\_ab\<FILM>\off\kunye.txt --title "..." --profile film
```

Çıktılar: `E:\MITAS\outputs\_ab\<FILM>\{off|on}\kunye.txt`, `ocr_summary.json`, `master.png` (ON'da)

**Not:** Rol-eval için `qwen3:8b` model adı üretimde `format=json_schema` ile HTTP 500 döndürüyor (Ollama 0.30.7 + atlas1 build). `MITAS_CREDIT_TEXT_MODEL=qwen3:8b-atlas1` + `format=json` (şemasız) ile çalıştırıldı — bu ayrı bir açık.
